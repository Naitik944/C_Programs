# Basic Arithmetic Operations in C

## Problem Statement

Write a C program that uses variables and expressions to perform basic
arithmetic operations on two integers.

## Operations

The program should:

- Read two integers from the user.
- Calculate their:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Floating-point division (`/`)
  - Modulus (`%`)
- Display the results.

## Sample Input

```text
20
6
```

## Sample Output

```text
Enter the value of a: 20
Enter the value of b: 6

Results:
Addition = 26
Subtraction = 14
Multiplication = 120
Division = 3.33
Modulus = 2
```
