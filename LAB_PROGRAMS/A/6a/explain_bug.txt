BUG EXPLANATION AND CODE CHANGES
================================

File: 6a.c


1. Input validation
-------------------

Original code (old lines 15-18):

    printf("Enter number of elements:");
    scanf("%d",&n);

    input(a,n);

Changed code (lines 16-25):

    printf("Enter number of elements: ");
    if (scanf("%d", &n) != 1 || n <= 0 || n > 100) {
        printf("Invalid number of elements.\n");
        return 1;
    }

    if (!input(a, n)) {
        printf("Invalid element input.\n");
        return 1;
    }

Reason:
The old code accepted zero, negative, or greater-than-100 values. This could
cause invalid array access or division by zero. The new code accepts only
values from 1 to 100 and checks whether scanf successfully read an integer.


2. Element input validation
---------------------------

Original code (old lines 27-31):

    void input(int a[], int n) {
        int i;
        for (i=0;i<n;i++) {
            scanf("%d",&a[i]);
        }
    }

Changed code (lines 4 and 36-43):

    int input(int a[], int n);

    int input(int a[], int n) {
        for (int i = 0; i < n; i++) {
            if (scanf("%d", &a[i]) != 1) {
                return 0;
            }
        }
        return 1;
    }

Reason:
The old function could not report invalid input. It now returns 0 when an
element is not an integer and returns 1 when all elements are read correctly.


3. Largest element
------------------

Original code (old lines 40-49):

    largest=a[0];
    for (i=1;i<n;i++) {
        if (a[i]>largest) {
            largest=a[i];
        }
        return largest;
    }

Changed code (lines 53-61):

    int largest = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > largest) {
            largest = a[i];
        }
    }

Reason:
The old return statement was inside the loop, so only one comparison was
performed. The return statement was moved outside the loop so every element
is checked.

5. Mean calculation
-------------------

Original code (old lines 60-64):

    float mean;
    mean=sum/n;
    return mean;

Changed code (lines 73-75):

    float findMean(int sum, int n) {
        return (float)sum / n;
    }

Reason:
The old expression performed integer division because both sum and n were
integers. Casting sum to float preserves the decimal part of the mean.


6. Standard deviation
---------------------

Original code (old lines 65-72):

    float sum,stdDeviation;
    for (int i=0;i<n;i++) {
        sum+=(a[i]-mean)*(a[i]-mean);
        stdDeviation=sqrt(sum/n);
    }
    return stdDeviation;

Changed code (lines 77-84):

    float sum = 0.0f;
    for (int i = 0; i < n; i++) {
        float difference = a[i] - mean;
        sum += difference * difference;
    }
    return sqrtf(sum / n);

Reason:
The old sum variable was uninitialized, so it contained an undefined value.
The standard deviation was also calculated during every loop iteration
instead of after the complete sum of squared differences was calculated.
The new code initializes sum, completes the loop first, and then calculates
the population standard deviation using sqrtf().

-----------------------------------

Changed code (lines 12, 86-91):

    void output(int sum, int largest, int smallest, float mean,
                float stdDeviation) {
        printf("Sum = %d\n", sum);

Reason:
Using main(void) clearly states that main accepts no arguments. Consistent
