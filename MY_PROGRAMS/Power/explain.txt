LINE-BY-LINE CODE EXPLANATION
=============================

This project reads a base and a non-negative exponent, calculates the power,
and prints the result. It contains the following files:

- main.c: program entry point and user input/output
- power.c: implementation of the power calculation
- power.h: function declaration and include guard
- CMakeLists.txt: CMake build configuration


1. main.c
==========

Line 1: #include <stdio.h>
Includes the standard input/output library. This provides printf, scanf, and
fprintf.

Line 2: #include "power.h"
Includes the project's local header file. The quotes tell the compiler to look
for power.h in the project directory.

Line 3: Blank line.
Separates the include directives from the program code for readability.

Line 4: int main(void) {
Defines the main function, where program execution begins. The int return type
means the function returns an integer status code. The void parameter list
explicitly means that the program accepts no command-line parameters.

Line 5:     int base;
Declares an integer variable named base. It stores the number whose power will
be calculated.

Line 6:     int exponent;
Declares an integer variable named exponent. It stores how many times base is
multiplied by itself.

Line 7: Blank line.
Separates variable declarations from the first input operation.

Line 8:     printf("Enter base: ");
Displays a prompt asking the user to enter the base. The text does not contain
a newline, so the cursor remains on the same line.

Line 9:     if (scanf("%d", &base) != 1) {
Reads an integer from standard input and stores it in base. The & operator
passes base's memory address to scanf so scanf can write the user's value.
scanf returns the number of successfully read values. If it is not 1, the
input was not a valid integer, so the error branch is executed.

Line 10:         fprintf(stderr, "Please enter a valid integer base.\n");
Prints an error message to stderr, the standard error stream. The newline
character moves the cursor to the next line.

Line 11:         return 1;
Stops the program and returns status code 1. A non-zero status normally
indicates that an error occurred.

Line 12:     }
Closes the if block that handles invalid base input.

Line 13: Blank line.
Separates base input handling from exponent input handling.

Line 14:     printf("Enter exponent: ");
Displays a prompt asking the user to enter the exponent.

Line 15:     if (scanf("%d", &exponent) != 1 || exponent < 0) {
Reads an integer into exponent and checks two conditions. The first condition
checks whether the input was a valid integer. The second condition rejects
negative exponents. The || operator means that the block runs if either
condition is true.

Line 16:         fprintf(stderr, "Please enter a base and a non-negative integer exponent.\n");
Prints an error message when the exponent input is invalid or negative.

Line 17:         return 1;
Stops the program with an error status code.

Line 18:     }
Closes the if block that handles invalid exponent input.

Line 19: Blank line.
Separates input validation from the calculation and output.

Line 20:     printf("The power result is: %d\n", power(base, exponent));
Calls the power function with base and exponent. The function's integer result
is inserted into the %d placeholder and printed. The newline moves the cursor
to the next line.

Line 21:     return 0;
Ends main successfully and returns status code 0, which conventionally means
the program completed without an error.

Line 22: }
Closes the main function.


2. power.c
===========

Lines 1-3:
//
// Created by Naitik Singh on 13/10/26.
//
These are comments generated by the IDE. The compiler ignores them. They record
the file creator and creation date.

Line 4: Blank line.
Improves readability between the comment and the include directive.

Line 5: #include "power.h"
Includes the declaration of the power function so its definition in this file
matches the declaration used by the rest of the program.

Line 6: Blank line.
Separates the include directive from the function definition.

Line 7: int power(int base, int exponent) {
Defines a function named power. It accepts two integers, base and exponent,
and returns an integer result.

Line 8:     int result = 1;
Creates result and initializes it to 1. Starting at 1 is important because 1
is the multiplicative identity and it also correctly handles any base raised
to the exponent 0.

Line 9: Blank line.
Separates initialization from the loop.

Line 10:     for (int i = 0; i < exponent; i++) {
Starts a loop. i begins at 0, the loop continues while i is smaller than
exponent, and i increases by 1 after every iteration. Therefore, the loop runs
exactly exponent times.

Line 11:         result *= base;
Multiplies result by base and stores the new value back in result. This is
equivalent to result = result * base.

Line 12:     }
Closes the for loop.

Line 13: Blank line.
Separates the calculation loop from the return statement.

Line 14:     return result;
Returns the calculated power to the caller in main.c.

Line 15: }
Closes the power function.

===========

Lines 1-3:

Improves readability.

Line 5: #ifndef POWER_POWER_H
Begins an include guard. It asks the preprocessor whether the name
POWER_POWER_H has not already been defined.

Line 6: #define POWER_POWER_H
Defines POWER_POWER_H. If this header is included again, the #ifndef condition
will be false and the declarations will not be included a second time.

Line 7: Blank line.
Separates the guard from the function declaration.

Line 8: int power(int base, int exponent);
Declares the power function without implementing it. This tells the compiler
that the function exists, accepts two integers, and returns an integer.

Line 9: Blank line.
Improves readability before the end of the include guard.

Line 10: #endif //POWER_POWER_H
Ends the #ifndef block. The trailing comment identifies which conditional
directive this #endif belongs to.


4. CMakeLists.txt
=================

Line 1: cmake_minimum_required(VERSION 4.3)
Tells CMake that this project requires CMake version 4.3 or newer.

Line 2: project(Power C)
Names the project Power and tells CMake that it uses the C programming
language.

Line 3: Blank line.
Separates project metadata from compiler settings.

Line 4: set(CMAKE_C_STANDARD 11)
Requests the C11 language standard when compiling the project.

Line 5: Blank line.
Separates the language standard setting from the target definition.

Line 6: add_executable(Power
Starts a CMake command that creates an executable target named Power.

Line 7:         main.c
Adds main.c to the executable target.

Line 8:         power.c
Adds power.c to the executable target.

Line 9:         power.h)
Adds power.h to the target's file list and closes the add_executable command.
The header is listed so IDEs and build tools show it as part of the project;
the C compiler compiles the .c files.


5. PROGRAM FLOW
===============

1. Execution starts in main.
2. The user enters a base.
3. The program checks that the base is an integer.
4. The user enters an exponent.
5. The program checks that the exponent is an integer and is not negative.
6. main calls power(base, exponent).
7. power multiplies base by itself exponent times.
8. The result is returned and printed.
9. The program returns 0 to indicate success.

Example:

Input:
    base = 2
    exponent = 8

Calculation:
    1 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2

Output:
    The power result is: 256

Note: Because the program uses int, very large results can overflow the
integer range supported by the system. The current program is suitable for
values whose result fits in an int.
